    Settings
    
        
      
    
      
    Press O anytime to open or close. Gameplay pauses while open. Tuners persist in this browser.
    
      
    
        
        
      
    

      
    
        
    Game style
    
        
    
          
          
        
    
        
    Sim = HoB + ballistic zero. Arcade = reticle-faithful (bore = camera aim).
    
      
    

      
    
        
    Display
    
        
        
        
        
        
    1.00 / 1.00 is ungraded sRGB. Scene time-of-day owns the look; use the sliders if your panel is dim.

    White
    
        
    
        
        
    If Black blends into Low, your display is crushing shadows — raise Brightness/Gamma.
    
      
    

      
    
        
    FX
    
        
        
        
        
        
        
        
    Env / silhouette holes FIFO-cap and optionally expire. Paper-target holes stay until table reset. Berm popups still clear on hide. Casings sleep, then expire (0 = until the cap recycles). Cap and fade pick at random from the oldest third so brass does not vanish in firing order. Draw distance only hides (holes/crater plugs vs casings/spent slugs) — walk back and they reappear. Caps stay.
    
      
    

      
    
        
    Lighting
    
        
        
        
    Scene sun, sky, and fog. Display brightness/gamma stay as grade. Default evening keeps the dusk range; night stays dark (stars, not a washed navy). Clouds 0 = clear. Stars follow the clock. Intensity sliders multiply the current clock (1.00 = authored ToD).
    
        
        
        
        
        
        
        
        
        
        
    Size is the visual disc + sky halo only (real sun ≈ 0.5°). It does not grow bloom. Punch is how hot the tiny core is — soft-clamped so it never floods. Halo stays dimmer and below the bloom threshold.
    
        
        
    Occlusion shafts from the sun shadow map, not a glow ball. Strongest looking toward low sun down the bay; fall off looking aside; noon is milder; night is off. Intensity lengthens / brightens streaks. 0 = skip the pass.
    
        
        
    HDR glow on floods, muzzle, tracers, hot barrels, and a tiny sun core — not a second sun. Sky halo stays out of the bright-pass. 0 = skip the pass.
    
        
        
        
        
        
        
        
    Banding floor after tone map, not grain. Default hash is luma-only TPDF (no color sparkle, not a square grid). Scale changes pattern frequency; offsets slide it in pixels. IGN/Bayer are optional. Animate is off — frame crawl looks digital. Night lifts a hair; sky stays black. 0 = skip the pass.
    
        
        
    Orange/amber barrel glow from rounds through the tube. A mounted suppressor takes some of that heat on the can. SMG auto dumps cook fast; rifle warms on rapid fire; bolt barely ticks. Cools over a few seconds. 0 = off.
    
      
    

      
    
        
    Materials
    
        
        
        
        
    Wear is dust and edge fade. Scale is grain size (low = finer grit, high = larger blotches). Variation is per-panel hue/value drift. Mid-slider is the authored look — ends are useful, not one-tick. Default already reads as poured panels. Benches stay wood.
    
      
    

      
    
        
    Fog
    
        
        
        
        
    Linear distance fog (THREE.Fog). Color tracks clear/background. Density (FogExp2) not exposed yet.
    
      
    

      
    
        
    Camera clip
    
        
    Near/far planes for depth teaching. Default far 2000 so looking up does not clip at 520 m; fog 375/520 still hides long tracers. Logarithmic depth is on.
    
        
        
      
    

      
    
        
    Ballistics
    
        
        
    Zero distance mainly applies in Sim.
    
      
    

      
    
        
    Look
    
        
        
        
        
        
    ADS viewmodel only (half-res). Ring taps plus center, plus a half-radius inner ring. Range stays sharp.
    
      
    

      
    
        
    Stance
    
        
        
    0% stand · 100% sit on heels. Mouse wheel while playing (pointer locked) also sets this. Sprint + crouch starts a short slide. No Ctrl bind (browsers steal it).
