    Settings
    
        
    
          
          
          
        
    
      
    
      
    Press O to open or close. Gameplay pauses. Tuners persist in this browser.
    

      
    
        
    Game style
    
        
    
          
          
        
    
        
    Sim = HoB + ballistic zero. Arcade = reticle-faithful (bore = camera aim).

    Pass lab
    
        
        
        
        
        
        
    Flat chart default (screen-space). Optional world far-quad for in-scene haze. PIP: final / scene / heat grab (heat fills only with ground haze). P saves full + PIP. Off by default. ?passlab=chroma&pip=1&src=scene · ?tod=22&heat=1.
    
      
    

      
    
        
    FX
    
        
        
        
        
        
        
        
    Env/silhouette holes FIFO-cap and can expire. Paper holes wait for table reset. Casings sleep then fade (0 = until cap recycles). Cap/fade pick from the oldest third (no firing-order zipper). Draw distance hides only — walk back and they return.
    
      
    

      
    
        
    Lighting
    
        
        
        
    Sun / sky / fog. Brightness/gamma stay as grade. Default dusk; night stays dark. Clouds 0 = clear. Intensities multiply the clock (1.00 = authored).
    
        
        
        
        
        
        
        
        
        
        
    Size = disc + sky halo only (real sun ≈ 0.5°), not bloom. Punch is the tiny core (soft-clamped). Halo stays below bloom.
    
        
        
    Occlusion shafts from the sun shadow map, not a glow ball. Strongest toward low sun; noon milder; night off. 0 = skip.
    
        
        
    HDR glow on floods, muzzle, tracers, hot barrels, tiny sun core — not a second sun. 0 = skip.
    
        
        
        
        
        
        
        
    Banding floor after tone map, not grain. Hash = luma TPDF. Scale = frequency; offsets slide in px. Animate off (looks digital). 0 = skip.
    
        
        
    Orange/amber glow from rounds through the tube. A can takes some heat. SMG cooks fast; rifle warms; bolt barely ticks. 0 = off.
    
        
        
        
    
          
          
          
        
    
        
    Barrel cards: lattice on the tube (bottoms locked; tops rise / trail). Vertex displace only — no grab composite. Cards default ON. Ground / height-fog is the only grab path and stays off. Master or strength 0 kills both. Size scales noise / lobe. Scene fog is a separate Fog control. Barrel heat slider stays the orange on the steel.
    
      
    

      
    
        
    Materials
    
        
        
        
        
    Wear = dust / edge fade. Scale = grain (low finer, high blotchier). Variation = per-panel value drift. Mid-slider is authored. Benches stay wood.
    
      
    

      
    
        
    Fog
    
        
        
        
        
    Linear THREE.Fog (color tracks clear). Not heat haze — Lighting heat toggles do not change bay fog. Floor shimmer is Lighting → Ground haze (off).
    
      
    

      
    
        
    Camera clip
    
        
    Depth planes. Default far 2000 so looking up does not clip at 520 m; fog 375/520 still hides tracers. Log depth on.
    
        
        
      
    

      
    
        
    Ballistics
    
        
        
    Zero distance mainly applies in Sim.
    
      
    

      
    
        
    Look
    
        
        
        
        
        
    ADS viewmodel only (half-res). Ring taps + center + inner ring. Range stays sharp.
